# TeamsMd Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A standalone Windows exe with a Markdown text box and a "Copy for Teams" button that puts formatted HTML on the clipboard.

**Architecture:** `TeamsMd.Core` is a UI-free library targeting `net10.0`. It converts Markdown to HTML with Markdig, wraps the HTML in the Windows CF_HTML clipboard format, and builds the clipboard payload. It's unit-tested on Linux. `TeamsMd.App` is a thin WinForms shell targeting `net10.0-windows` that hands the payload to the clipboard. It's cross-compiled from Linux into one self-contained exe.

**Tech Stack:** .NET 10 SDK, C#, WinForms, Markdig (latest stable), xUnit.

**Spec:** `docs/superpowers/specs/2026-11-18-teamsmd-design.md`

## Global Constraints

- .NET 10 (LTS). Core targets `net10.0`, App targets `net10.0-windows` with `<UseWindowsForms>true</UseWindowsForms>` and `<EnableWindowsTargeting>true</EnableWindowsTargeting>`.
- Markdig extensions: pipe tables, strikethrough (emphasis extras), task lists, autolinks. No other extensions.
- HTML output uses plain semantic tags only, with no `class=` attributes.
- The clipboard gets two formats: HTML (CF_HTML) and the original Markdown as plain text.
- CF_HTML offsets are UTF-8 byte offsets.
- Publish command: `dotnet publish src/TeamsMd.App -c Release -r win-x64 --self-contained -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true -o publish`
- UI: button text `Copy for Teams`, shortcut Ctrl+Enter, success status `Copied`.

## Review Focus

1. **Non-ASCII text** (accents, CJK, emoji): the CF_HTML offsets must still point exactly at the fragment, or Teams pastes garbage. Pinned in Task 2.
2. **Angle brackets in prose** (`List<string>`, a literal `<b>`): these must show up as text and must not be swallowed as raw HTML. Pinned in Task 1.
3. **Windows line endings** (`\r\n` from pasting on Windows) must give the same HTML as `\n`. Pinned in Task 1.
4. **Empty or whitespace-only input:** the clipboard is left untouched and the status says there's nothing to copy. Pinned in Task 2 (null payload) and Task 3.
5. **Clipboard locked by another app:** the app retries, then shows the error in the status line without crashing. Pinned in Task 3 (manual check).

### Task 2: CF_HTML wrapper and clipboard payload

**Files:**
- Create: `src/TeamsMd.Core/CfHtml.cs`, `src/TeamsMd.Core/ClipboardPayload.cs`
- Test: `tests/TeamsMd.Core.Tests/CfHtmlTests.cs`, `tests/TeamsMd.Core.Tests/ClipboardPayloadTests.cs`

**Interfaces:**
- Consumes: `MarkdownConverter.ToHtml(string)`.
- Produces:
  - `public static class CfHtml { public static string Build(string htmlFragment); }`
  - `public sealed record ClipboardPayload(string CfHtml, string PlainText) { public static ClipboardPayload? FromMarkdown(string markdown); }`
  
  `FromMarkdown` returns `null` when the input is null, empty or whitespace. Otherwise `PlainText` is the original Markdown, unchanged.

- [ ] **Step 1: Write failing tests**

Put a test helper in `CfHtmlTests`: `static int Offset(string cf, string key)`, which reads the 10-digit number after `key + ":"` in the header.

```csharp
[Theory]
[InlineData("<p>hi</p>")]
[InlineData("<p>café — 日本 😀</p>")]                       // Review Focus 1
public void Offsets_point_at_fragment(string frag) {
    var cf = CfHtml.Build(frag);
    var bytes = Encoding.UTF8.GetBytes(cf);
    Assert.StartsWith("Version:0.9\r\n", cf);
    string Slice(int a, int b) => Encoding.UTF8.GetString(bytes, a, b - a);
    Assert.Equal(frag, Slice(Offset(cf, "StartFragment"), Offset(cf, "EndFragment")));
    Assert.StartsWith("<html>", Slice(Offset(cf, "StartHTML"), bytes.Length));
    Assert.Equal(bytes.Length, Offset(cf, "EndHTML"));
}
```

```csharp
[Theory] [InlineData("")] [InlineData("   \r\n\t")] [InlineData(null)]   // Review Focus 4
public void Blank_input_gives_null(string? md) => Assert.Null(ClipboardPayload.FromMarkdown(md!));

[Fact] public void Payload_has_html_and_original_markdown() {
    var p = ClipboardPayload.FromMarkdown("**b**")!;
    Assert.Equal("**b**", p.PlainText);
    Assert.Contains("<!--StartFragment--><strong>", p.CfHtml.Replace("<p>", ""));
}
```

- [ ] **Step 2: Run the tests and confirm they fail**: `dotnet test`. Expected: a compile failure.

- [ ] **Step 3: Implement `CfHtml.Build`**

Layout: header lines `Version:0.9`, `StartHTML:`, `EndHTML:`, `StartFragment:`, `EndFragment:`, each value a zero-padded 10-digit number and each line ending `\r\n`. Then `<html><body>\r\n<!--StartFragment-->` + fragment + `<!--EndFragment-->\r\n</body></html>`. Because the header is a fixed length, you can compute every offset with `Encoding.UTF8.GetByteCount` on the pieces before it.

- [ ] **Step 4: Implement `ClipboardPayload.FromMarkdown`**: return null for blank input, otherwise `new(CfHtml.Build(MarkdownConverter.ToHtml(md)), md)`.

- [ ] **Step 5: Run the tests and confirm they pass**: `dotnet test`. Expected: all pass.

- [ ] **Step 6: Commit**: `git add -A && git commit -m "feat: CF_HTML wrapper and clipboard payload"`

- [ ] **Step 1: Create the App project**

Write the csproj by hand: `OutputType=WinExe`, `TargetFramework=net10.0-windows`, `UseWindowsForms=true`, `EnableWindowsTargeting=true`, `Nullable=enable`, `AssemblyName=TeamsMd`, and a project reference to Core. Add it to the solution.

- [ ] **Step 2: Implement `MainForm` in code (no designer file)**

- Window: title `TeamsMd`, about 700×500, resizable.
- Layout: a multiline `TextBox` filling the window (Consolas, vertical scrollbars, `AcceptsReturn`, `AcceptsTab`), with a bottom panel holding a status `Label` on the left and a `Copy for Teams` button on the right.
- Ctrl+Enter, handled in `ProcessCmdKey`, does the same as clicking the button.
- Copy logic:
  - If `FromMarkdown` returns null, set the status to `Nothing to copy` and leave the clipboard alone.
  - Otherwise build a `DataObject`. Call `SetData(DataFormats.Html, payload.CfHtml)`, then `SetData(DataFormats.UnicodeText, payload.PlainText)`. WinForms writes the Html format as UTF-8, which is why Task 2 uses UTF-8 offsets.
  - Then call `Clipboard.SetDataObject(data, copy: true, retryTimes: 10, retryDelay: 100)` and set the status to `Copied`.
  - Catch `ExternalException` and set the status to `Clipboard busy — try again` (Review Focus 5).

`Program.Main` must be `[STAThread]`, call `ApplicationConfiguration.Initialize()`, then run the form.

Run: `dotnet build -c Release && dotnet test`. Expected: the build succeeds with 0 errors and all tests pass.
